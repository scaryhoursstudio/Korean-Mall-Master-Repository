# Korean Mall Plugins

A directory of standalone Old School RuneScape plugins for the RuneLite client.

**Current status:** every linked repository is a RuneLite starter template. The descriptions below describe each plugin's intended purpose, not functionality already present in the public starter. These are not Plugin Hub releases or installation links.

## Combat and equipment

| Plugin | Purpose | Status |
| --- | --- | --- |
| [Deeps](https://github.com/scaryhoursstudio/deeps) | Solo and party DPS tracking with fight phases and history. | RuneLite starter template; implementation not ported yet |
| [DPS WorkBench](https://github.com/scaryhoursstudio/dps-workbench) | Compare owned and budget gear loadouts for a chosen monster. | RuneLite starter template; implementation not ported yet |
| [Vitals](https://github.com/scaryhoursstudio/vitals) | Display-only combat HUD for hitpoints, prayer, and status warnings. | RuneLite starter template; implementation not ported yet |
| [Spec Pulse](https://github.com/scaryhoursstudio/spec-pulse) | Track special-attack energy, hits, and damage on the current target. | RuneLite starter template; implementation not ported yet |
| [Click Cue](https://github.com/scaryhoursstudio/click-cue) | Show a tick-based cue when an action finishes. | RuneLite starter template; implementation not ported yet |
| [Kitted Out](https://github.com/scaryhoursstudio/kitted-out) | Save equipment loadouts and recall them as checklists. | RuneLite starter template; implementation not ported yet |
| [Item Lock](https://github.com/scaryhoursstudio/item-lock) | Protect selected items from accidental consumption, dropping, or breaking. | RuneLite starter template; implementation not ported yet |
